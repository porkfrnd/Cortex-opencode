Cortex memory operation: $ARGUMENTS

- `/cortex-memory search <query>` → cortex_memory action=search
- `/cortex-memory consolidate` → cortex_memory action=consolidate
- `/cortex-memory clear-project` → cortex_memory action=clear-project

Memory is local-first, redacted, and project-isolated.
